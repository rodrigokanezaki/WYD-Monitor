# Changelog

Todas as mudanças relevantes do WYD Monitor serão registradas neste arquivo.

O projeto segue versões no formato `MAJOR.MINOR.PATCH`, usando identificadores `beta` enquanto estiver em pré-lançamento.

## [1.0.0-beta.7] - 2026-09-30

### Primeira versão pública

- Publicação inicial do código-fonte.
- Dashboard nos modos Gamer e Work.
- Monitoramento de múltiplos personagens.
- Exibição de status, HP, gold e moedas.
- Pesquisa global de itens.
- Alertas configuráveis por personagem.
- Agenda de eventos.
- Painel de consulta pelo celular.
- Suporte à conexão entre dois computadores.
- Configurações de aparência.
- Estrutura modular em PowerShell.
- Interface desktop baseada em WebView2.
- Primeira distribuição pública pela página de Releases.

### Segurança e distribuição

- Dados pessoais e credenciais locais excluídos da versão pública.
- Arquivos sensíveis adicionados ao `.gitignore`.
- Projeto publicado sob GPL-3.0.
